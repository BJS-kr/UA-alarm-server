# ADR-0037. 런타임·기본 기술 스택 선정 및 전송 여부 미확정 판정 기준

## 배경

런타임 및 기본 도구를 선정하고, HTTP 클라이언트 계층에서 전송 여부 미확정(`UNCONFIRMED`) 오류를 구분하는 기술적 기준을 정의한다.

## 결정

| 항목            | 선택                                    | 선정 이유                                                                                                                              |
| --------------- | --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| Node.js         | 24 LTS                                  | 현행 LTS 버전이며 개발 환경과 동일하다. Node 26은 2026년 10월 말에 LTS로 전환된다                                                      |
| NestJS          | 12                                      | 최신 메이저 버전(2026-08). TypeScript는 Nest CLI가 사용하는 6.0을 따른다(TS 7 미지원)                                                  |
| PostgreSQL      | 18                                      | 내장 `uuidv7()` 함수를 지원하여 별도 확장이 필요 없다                                                                                  |
| 알림 ID         | UUIDv7 (DB 기본값)                      | UUID 형식 요구사항을 충족하면서 ID 순서가 곧 생성 순서가 된다. 목록 커서(ADR-0024)를 단일 ID로 구성하고 인덱스에도 순차적으로 기록된다 |

| 입력 검증       | `class-validator` + `class-transformer` | NestJS 표준 조합이다. `forbidNonWhitelisted`로 정의되지 않은 필드를 거부한다(ADR-0021)                                                 |
| OpenAPI         | `@nestjs/swagger`                       | 컨트롤러와 DTO에서 명세를 생성해 `/docs`로 제공하고, `docs/openapi.json`을 저장소에도 커밋한다. 문서의 `openapi` 필드는 `3.0.x`다      |
| 패키지 매니저   | `npm`                                   | Node.js에 기본 포함되어 있어 추가 도구가 필요 없다                                                                                     |

## 상세

### 전송 여부 미확정(`UNCONFIRMED`) 오류의 판정 기준

판정 기준은 **요청 바이트를 OS 커널에 모두 넘겼는가**(요청 스트림의 `finish` 이벤트 발생 여부) 하나다.

- **커널에 넘기기 전 실패**(연결 거부, 호스트 없음, 연결 수립 타임아웃 등): 외부 서버는 완전한 요청을 받지 못했으므로 처리할 수 없다. 전송되지 않은 것으로 판정하고 재시도한다(ADR-0014).
- **커널에 넘긴 후 실패**(응답 타임아웃, 응답 수신 도중 연결 끊김): 결과 미확정(`UNCONFIRMED`)으로 분류한다(ADR-0032).
- `keepAlive` 연결이 서버 측에서 이미 닫혀 있어 요청 바이트를 기록한 직후 끊기는 경우에도, 바이트를 넘긴 뒤이므로 결과 미확정(`UNCONFIRMED`)으로 분류한다. 실제로는 전송되지 않았을 가능성이 높으나 확신할 수 없으며, 추가 비용은 발송 내역 조회 1회뿐이다.

## 검토한 대안

- **연결 단계의 오류 코드 목록(`ECONNREFUSED` 등) 병행 검사**: 변이 테스팅에서 해당 조건을 제거해도 결과가 동일했다. 요청 스트림의 `finish` 여부 하나로 충분하다(ADR-0034).
