# ADR-0030. 설정은 환경변수로 받고, 기동할 때 값 사이의 관계까지 검사해 틀리면 시작하지 않는다

## 결정

- 모든 설정은 환경변수로 받는다. 기본값은 코드(`src/shared/config/app-config.ts`)와 `docker-compose.yml`에 두어 `docker compose up`만으로 실행되게 한다. 운영에서는 같은 이미지에 환경변수만 바꿔 배포한다.
- `@nestjs/config`를 쓰고, 검사는 DTO 검증과 같은 class-validator로 한다.
- 기동할 때 모든 값을 검사한다. 하나라도 틀리면 어떤 키가 왜 틀렸는지 출력하고 끝난다. 잘못된 설정으로 돌다가 발송 중에 드러나는 것보다 시작하지 않는 편이 안전하다.
- 기동할 때 실제 적용된 설정값을, 비밀값만 가려서(ADR-0028) 한 번 로그로 남긴다. 운영 중 "이 프로세스가 어떤 값으로 도는가"를 이 한 줄로 확인한다.

## 관계 검사

| 관계 | 뒤집히면 |
| --- | --- |
| 응답 한도 < 발송 기한, 사용자 조회 한도 < 작업 기한(ADR-0004) | 정상인 건이 응답을 기다리는 사이 넘겨받힌다 |
| 한 번에 꺼내는 수 ≤ 동시 발송 한도(ADR-0013) | 꺼낸 건을 보낼 자리가 없다 |
| 재시도 시작 간격 ≤ 최대 간격, 브레이커 최소 정지 ≤ 최대 정지(ADR-0014) | 간격이 늘지 않고 줄어든다 |
| api의 쿼리 한도 > 트랜잭션 유휴 한도(ADR-0039) | 멈춘 워커가 쥔 알림 행 잠금을 기다리던 발송 시작·취소가, 잠금이 풀리기 전에 503으로 끝난다 |
| api는 앱 DB 주소와 API 키, worker는 앱 DB 주소, migrate는 마이그레이션 DB 주소가 있어야 한다 | 시작해도 일을 할 수 없다 |

## 설정 항목 (기본값)

| 묶음 | 항목 |
| --- | --- |
| DB | 앱 계정 접속 주소, 마이그레이션 계정 접속 주소(ADR-0025), api의 연결 대기 한도 5초와 쿼리 한도 10초(ADR-0039) |
| 외부 API | 주소, 발송 한도 10초, 조회 한도 10초, 사용자 조회 한도 10초, 조회 대기 5초(ADR-0002), 사용자 페이지 크기 1000 |
| 처리량 | 초당 50, 버킷 용량 10, 한 번에 꺼내는 수 10, 동시 발송 한도 50(ADR-0009, 0013) |
| 재시도 | 시작 간격 1초, 최대 간격 60초, 최대 8번, 무작위 폭 ±20%(ADR-0014) |
| 서킷 브레이커 | 최근 20건, 실패 비율 절반, 정지 5~60초, 연달아 발동으로 보는 범위 60초(ADR-0014) |
| 기한과 넘겨받기 | 발송 기한 30초, 작업 기한 30초, 조회 기한 30초, 넘겨받기 주기 2초, 트랜잭션 유휴 한도 5초, 쉴 때 확인 0.5초(ADR-0004, 0011) |
| 운영 | 포트, 관리 포트, 로그 수준, API 키, 생존 판정 30초(ADR-0026), 정상 종료 때 응답을 기다리는 상한 20초(ADR-0007) |

## 검토한 후보

- **설정을 읽고 검사하는 모듈을 직접 작성**: 의존성이 하나 줄지만, NestJS 공식 모듈이라 읽는 사람에게 익숙하고 붙이는 비용이 작다.
