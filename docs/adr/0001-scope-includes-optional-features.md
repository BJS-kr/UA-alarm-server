# ADR-0001. 선택 구현(긴급 알림, 워커 다중화)을 처음부터 설계에 넣는다

## 결정

긴급 알림과 워커 다중화를 처음부터 설계에 넣는다. 구현 순서는 필수 기능, 워커 다중화, 긴급 알림이다. 기한이 모자라면 긴급 알림만 README에 설계 의도로 남긴다.

## 이유

- 워커 다중화는 시스템의 골격을 정한다. 여러 워커가 일을 어떻게 나눠 가지는지, 한 대가 죽으면 그 일을 누가 이어받는지, 처리량 제한을 어떻게 함께 지키는지가 여기서 나온다.
- 긴급 알림은 대기열의 구조와 우선순위 방식을 정한다.
- 워커 한 대, 알림 한 종류를 전제로 만들면 나중에 이 골격을 다시 짜야 한다.

## 결과

둘 다 구현했다.
