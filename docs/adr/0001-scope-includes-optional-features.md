# ADR-0001. 선택 요구사항(긴급 알림, 워커 다중화)을 초기 설계에 포함한다

## 배경

과제는 필수 요구사항과 선택 요구사항(긴급 알림, 워커 다중화)으로 구성된다. 긴급 알림과 워커 다중화는 작업 분배, 장애 복구, 대기열 우선순위 등 시스템 핵심 구조에 직접적인 영향을 미치므로 사후에 추가하기 어렵다.

## 결정

긴급 알림과 워커 다중화를 초기 설계 범위에 포함한다. 구현은 필수 기능, 워커 다중화, 긴급 알림 순서로 진행하며, 일정이 부족할 경우 긴급 알림은 README에 설계 의도만 기술한다.

## 근거

- 워커 다중화는 작업 점유(claim) 분배, 워커 장애 시 리스 만료 회수 및 인계(Takeover), 전역 초당 50건 처리량 제한(Rate Limit) 공유 방식을 결정한다.
- 긴급 알림은 대기열 스키마와 발송 점유 우선순위 정렬 방식을 결정한다.
- 단일 워커와 단일 우선순위를 전제로 설계하면 추후 코어 아키텍처를 재작성해야 한다.

## 결과

두 선택 요구사항을 모두 구현 완료했다.
