# 워커는 기본 2대, 컨테이너 하나에 프로세스 하나

처리량은 외부 상한(초당 50건)에 묶여 있고 Node의 비동기 I/O로 한 프로세스가 충분히 감당하므로 1대로도 된다. 그래도 compose의 기본 replicas를 2로 둔다.

- **가용성**: 1대면 그 워커가 죽었을 때 재시작될 때까지 발송이 멈춘다. 2대면 남은 워커가 바로 넘겨받는다.
- **다중 경로 상시 실행**: 넘겨받기와 동시 꺼내기가 개발 중에도 늘 실행되어, 다중 워커에서만 드러나는 버그가 숨지 않는다.
- 3대 이상은 처리량 이득 없이 DB 연결만 늘린다. `--scale worker=N`은 그대로 지원하고 테스트한다.
- 한 컨테이너 안에서 여러 프로세스(cluster 모드)를 띄우지 않는다. 워커 ID와 종료 처리를 "컨테이너 = 프로세스 = 워커 하나"로 단순하게 유지하기 위해서다.
