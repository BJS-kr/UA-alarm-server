# 심사 기준

구현 에이전트가 구현을 마친 뒤 띄우는 심사 에이전트용 문서다. 심사 에이전트는 매 회차 새 컨텍스트로 시작한다.

## 관점

심사의 기준은 원본 명세다. 우리 설계 문서(ADR, README, `docs/requirements.md`)는 기준이 아니라 심사받는 주장이다. "계획대로 만들었는가"를 묻지 않는다. 이 과제를 낸 평가자가 명세를 들고 이 구현을 봤을 때 납득하는가를 판단한다.

- 명세가 요구한 것을 실제로 만족하는가. 실행으로 확인한다.
- 명세의 상황(외부 API의 특성, 규모, 운영 환경 가정)에 비춰 설계 선택이 합리적인가. 과한 곳, 모자란 곳, 더 단순하거나 더 나은 방법이 있는 곳을 찾는다.
- 문서가 약속한 보장이 실제로 성립하는가. 주장과 구현이 다르면 어느 쪽이 틀렸는지 판단한다.
- 명세의 모호한 곳을 우리가 해석한 방식이 평가자가 받아들일 만한가.

## 심사 에이전트가 받는 것

- 원본 명세 `.local/assignment.md` (평가자의 힌트 포함)
- 저장소 전체 (코드, 문서)

구현 과정의 대화나 설명은 받지 않는다.

## 순서

우리 문서에 끌려가지 않도록, 문서는 코드와 실행 결과를 본 뒤에 읽는다.

### 1. 명세만 읽고 스스로 정리한다

문서를 보기 전에, 이 명세에서 무엇이 핵심이고 어디가 깨지기 쉬우며 평가자라면 무엇을 확인할지 목록으로 만든다. 이 목록을 보고서 앞에 그대로 싣는다.

### 2. 코드를 읽고 실행한다

1의 목록을 하나씩 코드와 실행 결과로 확인한다. 실행하지 않은 것은 통과로 보지 않는다. 기존 테스트에 없는 시나리오는 직접 만들어 돌려 본다(예: mock 설정을 바꿔 띄우기, 발송 도중 컨테이너 pause·kill, DB 재시작, 같은 알림에 동시 요청).

기본으로 확인할 것:

- 빌드, `docker compose --profile test run --rm test`
- `docker compose up` 뒤 모든 서비스가 healthy
- `bash scripts/e2e.sh`: 수신자마다 외부 기록이 정확히 한 번이고 429가 지속되지 않는다
- `docker compose --profile test run --rm test npm run test:mutation`: 점수와 살아남은 변이
- `docker compose --profile test run --rm test npm run test:sabotage`: 모든 고의 결함이 검출되는가

### 3. 문서를 읽고 판단한다

README, `docs/requirements.md`, `docs/adr`, `CONTEXT.md`를 읽는다.

- 결정마다 근거가 명세 상황에 비춰 설득력이 있는가. 기각한 대안이 더 나은 경우가 있는가.
- 문서가 약속한 보장(중복·누락, 워커 장애, 처리량 제한, 긴급 우선, 취소)이 2에서 본 실제와 맞는가.
- README가 제출 요구(설치·실행·테스트 방법, 요청·응답 예시, 구현 코멘트, 구현하지 못한 부분의 설계 의도, 명세 해석)를 담고, 사실과 다른 주장이 없는가.

### 4. 테스트가 무엇을 증명하지 못하는지 본다

통과하는 테스트가 명세의 보장을 실제로 지키는가. 빠진 시나리오, 결과 대신 구현을 확인하는 검증, 타이밍에 기대는 검증을 찾는다.

### 5. 지켜야 하는 규칙

- 승인 목록 밖의 의존성이 없다(`CLAUDE.md`).
- 원본 명세의 문장이 커밋되는 파일에 옮겨져 있지 않다(ADR-0038).

## 지적 형식

각 지적은 다음을 담는다.

- **심각도**: 차단(명세 위반, 중복·누락 가능성, 실행 실패, 사실과 다른 문서 주장) / 개선 / 참고
- **근거**: 명세의 어느 요구인지(`docs/requirements.md`의 ID가 있으면 함께), 관련 ADR
- **위치**: `파일:줄`
- **증거**: 재현 명령과 출력, 또는 코드 인용

추측은 "확인 필요"로 표시하고 차단으로 올리지 않는다.

납득되지 않는 설계 결정은 "설계 이의"로 따로 분류한다. 평가자가 어떤 반론을 할지와 대안을 적는다. 구현 에이전트는 설계 이의를 받으면 임의로 바꾸지 않고 사용자에게 보고한다.
