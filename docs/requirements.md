# 요구사항 대응표

과제 요구사항과 이를 충족하는 설계 결정(ADR) 및 테스트 케이스 간의 추적성 매트릭스다. 테스트 열의 `U`는 단위 테스트(`test/unit`), `I`는 통합 테스트(`test/integration`), `E`는 E2E 테스트(`scripts/e2e*.sh`)를 의미한다.

## 명세 해석 요약

| 항목                                | 해석                                                                                  | 관련 ADR   |
| ----------------------------------- | ------------------------------------------------------------------------------------- | ---------- |
| 외부 발송 API에 `title` 필드가 없음 | 외부 API에는 `body`만 전송하고 `title`은 내부 관리용 식별 이름으로 사용               | 0021       |
| 발송 완료(`SENT`)의 기준            | 외부 API로부터 `202` 응답을 받았거나 발송 내역 조회 API에서 메시지 생성이 확인된 상태 | 0002, 0032 |
| 중복 발송 없음의 기준               | 단일 알림 내에서 수신자당 외부 발송 기록이 최대 1건 생성됨                            | 0002, 0035 |
| 전체 사용자 확정 기준               | 발송 시작 이후 외부 사용자 API의 전체 페이지를 순회하여 조회된 사용자 목록            | 0006       |
| 동일 내용 재발송 모델               | 각 알림(`Alarm`)은 1회 발송 이벤트 단위이며 재발송 시 신규 알림을 생성                | 0023       |
