# 요구사항 대응표

과제 명세의 요구사항을 우리 말로 요약하고, 각 요구사항을 다루는 결정(ADR)과 그것을 지키는 테스트를 잇는다. 원본 명세는 비공개라 저장소에 두지 않는다(ADR-0038). 테스트 열의 U는 `test/unit`, I는 `test/integration`, E는 끝단 테스트다.

심사는 이 표의 왼쪽(요구사항)에서 출발해 오른쪽으로 따라간다. 연결된 ADR이 없는 요구사항은 빠뜨린 것이고, 어떤 요구사항에도 연결되지 않는 구현은 범위를 넘은 것이다.
